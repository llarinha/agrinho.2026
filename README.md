Para o desenvolvimento do site Agro Forte, foi utilizada a combinação das linguagens HTML, CSS e JavaScript, responsáveis pela estrutura, aparência e interatividade da página. Inicialmente, foi criado o arquivo HTML, que serviu como base para organizar todo o conteúdo do site. Nessa etapa, foram inseridos o cabeçalho com o nome da empresa e o menu de navegação, uma seção principal de apresentação (hero), a área "Quem Somos", os serviços oferecidos, a seção de notícias, os contatos e o rodapé.

Em seguida, foi desenvolvido o arquivo CSS, responsável pela estilização da página. Foram definidas as cores principais do projeto, utilizando tons de verde para representar a identidade visual do agronegócio. Também foram configuradas as fontes, espaçamentos, alinhamentos, efeitos de sombra, bordas arredondadas e animações de transição. A seção principal recebeu uma imagem de fundo com efeito escurecido para destacar os textos, enquanto os cartões de serviços ganharam efeitos visuais ao passar o mouse, proporcionando uma aparência mais moderna e profissional.

Na seção de serviços, foram criados três cartões informativos: Agricultura de Precisão, Consultoria Rural e Sustentabilidade. Cada cartão recebeu uma imagem ilustrativa, um título e uma descrição explicativa sobre sua respectiva área. Também foi criada uma seção de notícias para apresentar informações relacionadas ao agronegócio e uma área de contato contendo telefone e e-mail para comunicação.

Por fim, foi implementado o JavaScript para adicionar funcionalidades interativas ao site. Foi criado um botão de retorno ao topo da página, que aparece automaticamente quando o usuário rola a tela para baixo. Ao ser clicado, o botão realiza uma rolagem suave até o início do site. Além disso, foram adicionados efeitos de destaque nos blocos de notícias, aumentando levemente seu tamanho quando o cursor do mouse passa sobre eles.

Dessa forma, o projeto foi construído de maneira organizada, separando estrutura, estilo e funcionalidades em arquivos distintos. Essa divisão facilita futuras atualizações, melhora a manutenção do código e contribui para uma experiência visual agradável e intuitiva para os visitantes do site Agro Forte.
